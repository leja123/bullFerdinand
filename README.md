# RESCUE BULL FERDINAND

##  Navodila za igranje:

Ko zaženemo igro se odpre main menu na katerem lahko izbiramo med 5 možnostmi.<br>
V CLI vpišemo številko od 1-5 in s tem izbiramo med možnostmi.<br>
Če izberemo mmožnost 5 (Play) se igra začne.<br>
Igralca po zaslonu premikamo s puščicam, z držanjem space-a pa streljamo.<br>

## Potek igre
Na ekranu so ves čas nasprotniki, ki jih moramo pobivati.<br>
Areno se prikažejo ko smo od njih oddaljeni 200px.<br>
Level 1 ima 5 aren in vsaka arena ima 3 nasprotnike, level 2 pa ima isto 5 aren in vsaka arena ima 5 sovražnikov.<br>
Ko končamo level, se na ekranu pokažeta bik in vrata. Bika peljemo do vrat in nato nadaljujemo z igranjem.<br>
Ko končamo 2. level je igre konec in pokaže se replay.<br>
Med igro pa lahko pritisnemo tipko ESC in ustavimo igro.
